# CN Document Desk — Operating Repo

The executable version of the CN Document Desk master setup pack: a one-person
Chinese technical-document **procurement and verification** desk, Hyderabad.
Not a translation service. The product is access + provenance + accountability.

The original pack is preserved verbatim in [`master-plan.md`](master-plan.md).
Everything else in this repo is that pack broken into files you actually use.

## The one thing

**25 outreach contacts per week, every week.** Everything else in this repo is
scaffolding for that number.

**Week 3 gate:** does the mock sweep (`week-1/day-5-mock-sweep-design.md`)
show a real recall delta over free English/MT search? Answer honestly and let
the answer change the plan. Kill criteria live in
`project-1-sales-ops/knowledge/kill-criteria.md`.

## What was executed for you vs. what only you can do

Already drafted in this repo: the red-team critique of the plan (Day 1), the
CNKI/Wanfang agent-terms emails (Day 2), the target-list research method plus a
seeded 15-firm list (Day 3), the first outreach batch (Day 4), the mock-sweep
test design (Day 5), and reviewer recruitment materials (Days 6–7).

Only you can do: create the two claude.ai projects and paste the instructions,
load the Alipay/WeChat wallet and buy one test article, **send** the emails
(everything here is a draft until you verify names/addresses and hit send),
run the actual sweep, and hit 25 contacts a week.
